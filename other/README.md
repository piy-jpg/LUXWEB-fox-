# Supporting Materials, Documentation & Scripts

This folder contains supporting resources, API specifications, design tokens, and automation tools for the Lumière platform.

## Directory Structure

```text
other/
├── docs/                     # Project technical documentation
│   ├── api_spec.md           # REST API endpoint reference & schemas
│   └── architecture.md       # High-level architecture & dataflow diagrams
├── design/                   # Brand and UI design guidelines
│   └── brand_guidelines.md   # Colors, typography, and styling tokens
├── scripts/                  # Automation & maintenance scripts
│   └── setup.sh              # One-command project initializer
└── README.md                 # This overview
```

## Usage

### Run Setup Script
```bash
./other/scripts/setup.sh
```

### Review API Documentation
Open [docs/api_spec.md](docs/api_spec.md) for details on request/response payloads, query filters, and status codes.
